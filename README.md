# 🎮 Gamer Root
Projeto de catálogo de jogos consumindo API.

## 🚀 Funcionalidades

- Lista de jogos em tempo real
- Busca por nome
- Tela de detalhes do jogo
- Interface responsiva
- Design moderno estilo catálogo

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript
- RAWG API

## 📡 API utilizada

- https://rawg.io/apidocs

## 💻 Como executar

1. Clone o repositório: git clone https://github.com/SEU_USUARIO/gamer-root.git
2. Abra o arquivo `index.html` no navegador
3. Adicione sua API KEY no arquivo `script.js`

  const API_KEY = "SUA_CHAVE_AQUI";
